# grindes-sitio-web-interactivo
GRINDERS es un Webzine interactivo desarrollado como proyecto académico, enfocado en la creación de una revista digital moderna sobre la cultura del skateboarding.
El proyecto combina diseño editorial web, estructura semántica en HTML5, estilos avanzados en CSS3 y componentes interactivos en JavaScript, con el objetivo de simular una experiencia real de magazine digital contemporáneo.
No es solo una página informativa, sino una experiencia visual e interactiva que integra historia, cultura, referentes y contenido externo dentro de una interfaz dinámica y completamente responsive.

Objetivo General:
Desarrollar un Webzine interactivo que:
- Aplique correctamente estructura semántica en HTML5.
- Integre diseño visual moderno tipo editorial.
- Incorpore interactividad mediante JavaScript.
- Sea completamente responsive (desktop, tablet y móvil).
- Mantenga coherencia visual, narrativa y estructural.

Concepto Creativo
Grinders nace como una revista digital enfocada en la cultura skate, explorando:

- Orígenes del skateboarding
- Evolución histórica
- Trucos representativos
- Leyendas del skate
- Referencias externas a contenido real

Visualmente el proyecto utiliza:

- Diseño minimalista
- Composición centrada en imagen
- Overlays interactivos
- Sliders dinámicos
- Jerarquía tipográfica clara

El resultado busca transmitir energía, cultura urbana y modernidad.

Estructura del Proyecto
El Webzine está dividido en secciones principales:

1 Hero Section
Portada visual con identidad clara del proyecto.
2 Timeline (Historia)
Sección que presenta la evolución del skateboarding mediante bloques cronológicos organizados visualmente.
3 Tricks
Sección interactiva con slider horizontal mostrando diferentes trucos representativos.
4 Legends
Sección tipo galería interactiva con imágenes, overlay dinámico y navegación lateral.
5 Footer
Cierre editorial del Webzine.

Tecnologías Utilizadas

- HTML5 (estructura semántica)
- CSS3 (Flexbox, diseño responsive, transiciones)
- JavaScript Vanilla (manejo de sliders dinámicos BASICOS)
- Google Fonts (tipografía)

Responsive Design
El proyecto se trato de optimizar para:

- Desktop
- Tablet
- Celular promedio
- Celular pequeño

Se implementaron media queries estratégicas para garantizar:

- Adaptación de tamaños
- Reorganización de layout
- Escalado de imágenes
- Ajuste de navegación
- Correcta visualización de sliders

Interactividad Implementada

- Sliders horizontales con transición suave
- Overlay con efecto hover
- Navegación dinámica entre elementos
- Transiciones controladas con JavaScript
- Experiencia visual fluida
